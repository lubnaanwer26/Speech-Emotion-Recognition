# Speech Emotion Recognition 🎙️

A Deep Learning-based Speech Emotion Recognition application that predicts human emotions from speech audio.

## 📌 Project Overview

This project uses speech signal processing and deep learning to recognize emotions from audio recordings.

The application extracts MFCC (Mel-Frequency Cepstral Coefficients) features from speech and uses a trained CNN model to predict the emotion.

## 🧠 Technologies Used

- Python
- TensorFlow / Keras
- Librosa
- NumPy
- Scikit-learn
- Streamlit
- MFCC
- Convolutional Neural Network (CNN)

## 😊 Emotions Recognized

- Angry
- Calm
- Disgust
- Fearful
- Happy
- Neutral
- Sad
- Surprised

## 📂 Project Files

- `app.py` – Streamlit application
- `emotion_recognition_model.keras` – Trained deep learning model
- `label_encoder.pkl` – Emotion label encoder
